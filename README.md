# Stitchline

**Automatically generates and keeps up-to-date OpenAPI specifications by statically analyzing TypeScript router code and test suites.**

When API contracts drift, developers manually sync OpenAPI docs, leading to stale specs and broken client generation.
Keeping OpenAPI in sync with TypeScript routers and tests is tedious and error‑prone.
Stitchline removes the manual step by generating specs directly from the source and test suite.
